# Security Policy

## Supported Versions

Security updates are applied to the latest release of this fork.
See [releases](https://github.com/ergin84/minio/releases) for the current version.

## Reporting a Vulnerability

Security bugs in [ergin84/minio](https://github.com/ergin84/minio) should be reported by email to
**erginmehmeti@gmail.com**. Your email will be acknowledged within 72 hours.

Please provide a detailed explanation of the issue, including:
- Type of vulnerability (DoS, authentication bypass, information disclosure, etc.)
- Assumptions required for a successful exploit (e.g. valid credentials needed)
- Steps to reproduce

### Disclosure Process

1. The report is received and the issue is reproduced and assessed.
2. A response confirms or rejects the report with reasoning.
3. Code is audited for similar problems.
4. A fix is prepared and applied to the latest release.
5. A security advisory is published on this repository.

Please state in your report whether you wish to be credited for the finding.
By default your name will **not** be published to protect your privacy.
